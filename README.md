# Fictional University Theme (v0.1)

A WordPress theme project built as practice from Brad Schiff's Udemy course.  
This theme extends the tutorial with **Custom Post Types, Custom Fields, Custom Queries, Pagination, and Blog Archives**.  
Some functions (like `pageBanner()` in `functions.php`) were customized compared to the original tutorial.

---

## 🚀 Features (v0.1)
- Custom Post Types: Events, Blog
- Custom Fields integration
- Custom Queries for dynamic content
- Pagination for archives
- Custom theme structure: `fictional-university-theme`
- Work-in-progress Search functionality (incomplete)

---

## 📌 Notes
- This is the **first version (v0.1)** release.
